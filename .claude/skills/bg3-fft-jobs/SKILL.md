# FFTJobs — how the mod is built

Mod UUID `3db7be3e-9387-4678-b172-044acc7ff0c2` (never change it). Folder name / pak: `FFTJobs`. Needs BG3 Script
Extender (SE v33 on the user's PC; IMGUI uses `SetColor`/`SetStyle`, not `SetStyleColor`).

## Map
- `data/fft_jobs.json`: jobs (unlock rules, innate/mastery passives, equip, groups `""`/WotL/Special/Soul,
  `implemented`), badges, 411 abilities (cost, type Action/Reaction/Support/Movement, grants spells/passives/statuses,
  variants with `when`), one entry per line. Edit with `python3 tools/jobtool.py <spec.json>` (keeps the layout).
- `data/config_defaults.json`: every JP number and tunable + `help` text + presets (Classic default). Tests pin their
  own config (`tests/testlib.lua`), so changing a default rarely breaks tests; the pacing self-test checks targets.
- `data/strings.json` (UI strings), `data/souls.json` (Soul Collector, generated by `tools/souls_gen.py`),
  `data/vanilla_icons.json` (icons of vanilla parents, refreshed locally by `tools/menu_gen.py --vanilla-icons`).
- `stats_src/*.txt`: hand-written stats with placeholders `{{name:Id}}`, `{{desc:Id}}`, `{{str:Key}}`,
  `{{prof:Job}}`, `{{terrain:Water|Ice}}`; comments `//` stay here only.
- `tools/build.py` → generated (commit them): `Mod/Public/FFTJobs/Stats/Generated/Data/*.txt`,
  `Mod/Localization/English/FFTJobs.xml`, `Mod/Mods/FFTJobs/ScriptExtender/Lua/Shared/GeneratedData.lua`, icon atlas,
  root template. Generators it calls: `menu_gen.py` (hotbar job menus), `scaling.py` (+highest ability modifier on
  job damage/heals; ManeuverSaveDC -> SourceSpellDC), `upcast.py` (Chemist spell-slot levels), `souls_gen.py`, Echo/Arith
  twins, `statcast.py` (FFTJ_Cast_* passives, last, so it sees every spell).
- Lua (`Mod/Mods/FFTJobs/ScriptExtender/Lua/`): `Server/Service.lua` (the hub: events, SetPrimary/Learn/Equip, JP,
  menus), `Rules.lua` (pure rules + `DesiredGrants`), `Grants.lua` (apply the difference), `Effects.lua` (Lua-driven
  ability effects: steal, Chemist flasks, Poison/Acid ticks), `Game.lua` (all Osiris/Ext calls, wrapped in Try),
  `Bosses.lua` (boss badges), `Souls.lua`, `Commands.lua` (`!fft_*` console), `NetServer.lua` + `View.lua` +
  `Client/JobBoard.lua` (IMGUI Job Board), `Client/JobMenu.lua`, `State.lua` (mod vars), `Config.lua`.
- Tests: `tests/*.lua` with mocks of Osiris/Ext (`tests/mocks.lua`), run by `tools/run_lua_tests.py` (lupa) or Lua 5.4.
- Release: `tools/release.py <ver> --playtest a.md --status b.md`. Package/install (Windows only):
  `tools/package.ps1`, `tools/install.ps1`, `tools/uninstall.ps1`.

## Grants
A character's spells/passives/statuses = `Rules.DesiredGrants`; `Grants.Apply` adds/removes only what the mod
granted (`char.Granted`). Primary job: innate passives + learned actions; secondary: learned actions; slots: reaction
+ 2 passives; the main job's support/movement are always on; mastery perks kept. Job spells (and Echo twins) are
granted through hidden passives `FFTJ_Cast_<Str|Dex|Con|Int|Wis|Cha>_<spell>` (`tools/statcast.py`,
`UnlockSpell(<spell>,,,,<Ability>)`; slot spells `UnlockSpell(<spell>,AddChildren,d136c5d9-0ff0-43da-acce-a74a07f8d6bf,,<Ability>)`)
for `char.BestStat` (the highest ability, read on first sight and after level-ups only; `Rules.StatCastGrants`), so
spell attacks and SourceSpellDC() use it. Off (`Rules.HighestStatCasting` false) or scores unreadable: plain AddSpell,
except abilities with `castStat` (Chemist flasks: Intelligence). Menus, Job Board, souls: AddSpell. `FFTJ_Int_<X>` =
legacy, granted by nothing.

## BG3 stats facts (verified against vanilla data)
- Spell container: `SpellFlags IsLinkedSpellContainer`; a container shows EVERY `ContainerSpells` entry learned or
  not, so we leave it empty and let granted children join by `SpellContainerID` (vanilla MultipleSummon pattern).
- Upcast: `<root>_<N>` using the root, `RootSpellID`, `PowerLevel N`, `UseCosts ...;SpellSlotsGroup:1:1:N`; root
  Level must be 1+ (cantrips do not upcast).
- Metamagic Twinned (CommonConditions.khn): single target, AreaRadius 0, `IsSpell` flag, Projectile or Target type.
- Formulas accept expressions: `max(DexterityModifier,StrengthModifier)`, `max(1,2d8+...)`, LevelMapValue inside.
- `SetStatusDuration(STATUS,turns,Add|ForceSet)` lengthens in place (re-applying re-fires on-apply damage).
- No numeric cooldowns: N-turn recharge = caster status + `RequirementConditions "not HasStatus('X_CD')"`.
- DCs: `CalculateSpellDC(Ability.Intelligence, context.Source)`, `ManeuverSaveDC()`, `SourceSpellDC()`;
  `10+GetModifier(context.Source.Strength)` works in a SavingThrow.
- Vanilla children inherit through `using`: overriding a vanilla status (e.g. POISONED) also changes every vanilla
  status built on it; prefer Lua (exact status id) for global behaviour changes.
- Animations: NPC spells (e.g. `Projectile_FOR_GnomeGoblin_ThrowRock`) may carry NPC-only animations → players show
  none; copy a player spell's `SpellAnimation` (vanilla `Throw_Throw`).
- Icons: atlas lsx `Public/FFTJobs/GUI/*.lsx` + DDS + TextureBank; per-icon tooltip DDS 380 px; borrowed vanilla icons
  confuse players, so abilities have own art (`art/icons`, generated locally).
- Never ship a custom Alignment file or anything overriding vanilla factions (crashed saves in the DOS2 mod).

## Script Extender facts
- `Osi.DB_IsPlayer` does not exist in BG3; party = `Osi.DB_Players` + entities with `PartyMember`.
- Character creation runs on level `SYS_CC_I`: placeholders "Dummy"/"Player" exist there; nothing is tracked there.
- Osiris events used: CastedSpell/5, StatusApplied/4, StatusRemoved, TurnStarted/TurnEnded, CombatStarted/Ended,
  LevelGameplayStarted, AttackedBy/7, KilledBy/4, Died, TemplateAddedTo/4, DialogActorJoined, CharacterJoinedParty.
- Calls: `Osi.AddSpell`, `Osi.ApplyStatus(t, s, seconds, force, source)` (6 s per turn), `Osi.ApplyDamage(t, n,
  type, source)`, `Osi.HasActiveStatus`, `Osi.GetStatusTurns`, `Osi.IsPartyMember(g, includeCamp)`, `Osi.UseSpell`,
  `Osi.CreateAt`, `Osi.GetPosition`, `Ext.Net.CreateChannel` (client/server messages), `Ext.Loca.UpdateTranslatedString`.
- Never read Osiris DBs in a Tick handler while a save loads (native crash); guard with a game-state check.
- Playtest evidence = SE runtime logs (`%LOCALAPPDATA%\Larian Studios\Baldur's Gate 3\Script Extender Logs`, the user
  can paste/attach them); every grant change and board click is logged.
- `ModCrashSanityCheck` folder: if the game is killed before the main menu, the next start drops all mods.
- Multiplayer (1.0.0.63, unverified): the board opens with `NetServer.SendTo` (SendToClient + character GUID); board
  requests carry `From` (the client's ClientControl character) and `Service:MayChange` compares `Game:UserOf`
  (`Osi.GetReservedUserID`); party news via `Service:NotifyParty` (one character per player).

## Gotchas
- Generated files must be committed and up to date (`tools/build.py --check` in the tests).
- Write files with LF (`.gitattributes`); Python on Windows writes CRLF unless `newline="\n"`.
- Tooltip placeholders like `[1]` are whole phrases: never add "damage"/"metres" after them.
- FFT data sources: The Ivalice Chronicles game tables (local), Caves of Narshe for WotL; Fandom often returns 402.
